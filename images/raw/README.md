# Raw render output

Linear Radiance `.hdr` files: the renderer's output before any grade. The PNGs
in the gallery are these files run through
[`scripts/grade.py`](../../scripts/grade.py), so a different white point, bloom
strength or tone curve costs a second here instead of an hour of re-rendering.

Nothing in this directory is generated by a script. Each file is kept because a
gallery image depends on it, or because it is a frame worth re-grading later.

```
uv run scripts/grade.py images/raw/<file>.hdr out.png --white W --bloom B --tonemap aces
```

The naked-singularity frames render the full 45-degree frame at 3200x1800 and
evaluate only the central 1600x900 (`--from-row=450 --to-row=1350
--from-col=800 --to-col=2400`), which gives a 2x zoom at full resolution for the
cost of 1600x900 pixels. The 2026-09-27 zoom frames do the same at 3456x1944
for a central 1920x1080, a 1.8x zoom.

Not kept here: `render.hdr` and `black_body_spectrum.hdr` in the repository root.
Both are throwaway output, the second written by a unit test in
`src/rendering/black_body_radiation.rs`, and both regenerate on demand.
